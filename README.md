# অর্ধনারীশ্বর — ওয়েবসাইট

সাধারণ ই-কমার্স ধাঁচের সাইট: হোম, ক্যাটাগরি, প্রোডাক্ট ডিটেইলস, অর্ডার ফর্ম — আর একটি অ্যাডমিন প্যানেল যেখান থেকে কোড ছাড়াই প্রোডাক্ট যোগ/এডিট/ডিলিট করা যায়।

## ফাইল পরিচিতি
- `index.html` — মূল সাইট (কাস্টমার যা দেখবে)
- `admin.html` — অ্যাডমিন প্যানেল (শুধু আপনার জন্য)
- `products.json` — সব প্রোডাক্টের ডেটা (অ্যাডমিন প্যানেল এটাই আপডেট করে)
- `images/` — প্রোডাক্টের ছবি

## লাইভ করার ধাপ (একবারই)

### ১. GitHub-এ আপলোড
1. github.com-এ লগইন করে **New repository** তৈরি করুন (যেমন নাম: `ardhanarishwar-shop`, Public)।
2. "uploading an existing file" লিংকে ক্লিক করে এই ফোল্ডারের **সব ফাইল ও images ফোল্ডার** আপলোড করুন।
   (অথবা zip আপলোড করে GitHub-এই extract হয় না — ফাইলগুলো আলাদা করে সিলেক্ট করে আপলোড করুন।)

### ২. Vercel-এ লাইভ
1. vercel.com-এ GitHub দিয়ে লগইন করুন।
2. **Add New → Project** → আপনার repo সিলেক্ট করে **Import** → **Deploy**।
3. ১ মিনিটে লাইভ লিংক পাবেন (যেমন `ardhanarishwar-shop.vercel.app`)।

### ৩. অ্যাডমিন প্যানেল চালু (একবারই)
1. GitHub → আপনার প্রোফাইল ছবি → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. Repository access-এ শুধু এই repo সিলেক্ট করুন; Permissions-এ **Contents: Read and write** দিন; Generate করুন। টোকেনটি কপি করে রাখুন (একবারই দেখাবে)।
3. সাইটের `/admin.html` পেজে গিয়ে GitHub Username, Repository নাম আর টোকেন বসিয়ে **সেটিংস সেভ করুন**।

## প্রতিদিনের ব্যবহার (admin.html)
- **দাম বসাতে:** তালিকা থেকে প্রোডাক্ট → দাম লিখুন → "প্রয়োগ" → "সেভ ও পাবলিশ"। ১ মিনিটে লাইভ।
- **নতুন প্রোডাক্ট:** "＋ নতুন প্রোডাক্ট যোগ করুন" → নাম, ক্যাটাগরি, ছবি (আপলোড করলেই হবে), ডিটেইলস লিখে পাবলিশ।
- **ছবি বদলাতে:** প্রোডাক্ট সিলেক্ট করে নতুন ছবি আপলোড করুন — আগের ছবি বদলে যাবে।
- **ডিলিট:** প্রোডাক্ট সিলেক্ট → "ডিলিট করুন" → পাবলিশ।
- **Messenger লিংক:** দোকানের সেটিংসে আপনার পেজের `m.me/...` লিংক বসালে অর্ডারের পর কাস্টমার সরাসরি Messenger-এ পাঠাতে পারবে।
- দাম খালি রাখলে সাইটে "দাম জানতে ইনবক্স করুন" দেখাবে।

## অর্ডার কীভাবে আসবে
কাস্টমার অর্ডার ফর্ম পূরণ করলে একটি অর্ডার-বিবরণ তৈরি হয় — কাস্টমার সেটি কপি করে আপনার Messenger-এ পাঠাবে। অর্থাৎ অর্ডার আপনার ইনবক্সেই আসবে, যেমনটা এখন আসে।
